Isoline (snow peaks) - Windows preview

How to open
1. Extract the whole zip to a folder (do not run it from inside the zip).
2. Double-click start.bat.
   A small black window opens and your browser shows the page at http://localhost:5180/
3. Keep the black window open while you look. Close it to stop.

If Windows shows "Windows protected your PC": click "More info", then "Run anyway".
The script only serves the files in the "site" folder to your own computer.

Needs
- Windows 10 or 11, with Chrome or Edge (a recent version).
- An internet connection for the fonts (Google Fonts). Without it the page still
  runs, but the type falls back to system fonts.

Do not double-click site\index.html directly: browsers block the terrain data
when a page is opened as a file, and the scene will not load.

如何打开
1. 把整个压缩包解压到一个文件夹（不要在压缩包里直接运行）。
2. 双击 start.bat，会弹出一个黑色小窗口，浏览器自动打开 http://localhost:5180/
3. 观看期间保持黑色窗口开着，关掉它就停止。

如果 Windows 提示"已保护你的电脑"：点"更多信息"→"仍要运行"。
需要联网才能加载字体；不要直接双击 site\index.html，那样场景加载不出来。
